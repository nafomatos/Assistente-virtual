# Backtests

This directory stores validation reports generated by `scripts/run_cluster_validation.py`.

## Cluster Boost Validation

The **Cluster Boost Validation** workflow tests whether the cluster confidence boost
(Feature #4) improves signal accuracy before the flag is flipped to production.

It runs 4 historical periods × boost on/off = 8 backtests, then writes a markdown
verdict report here.

### How to trigger from the Actions tab

1. Go to the repository on GitHub
2. Click the **Actions** tab (top nav)
3. In the left sidebar, click **Cluster Boost Validation**
4. Click the **Run workflow** button (top right of the workflow list)
5. Fill in the inputs:
   - **Single period** — leave blank to run all 4 periods, or pick one for a quick check
   - **Force re-run** — tick to ignore cached results and re-run all API calls
   - **Smoke test** — tick to use synthetic data (no API calls, confirms wiring only)
6. Click **Run workflow**

The job takes up to 4 hours for the full 8-run suite (Claude Haiku API calls per trading day).
Cached results are reused automatically on re-runs unless **Force re-run** is ticked.

### What happens next

When the workflow completes it:

1. Writes `backtests/cluster_boost_validation_YYYYMMDD.md` with the full report
2. Commits the report to a new branch `validation/cluster-boost-YYYYMMDD`
3. Opens a pull request with the verdict and recommended action in the PR body

### Acting on the result

| Verdict | Action |
|---------|--------|
| **PASS** (≥ 3/4 periods improved by ≥ 3 pp at d+30) | Set `CLUSTER_BOOST_ENABLED=true` in GitHub Actions secrets or `.env` |
| **FAIL** | Read the "Recommended Action" section in the report before adjusting and re-running |

### Smoke test (wiring check)

To verify the harness end-to-end without any API calls:

```bash
python scripts/run_cluster_validation.py --smoke-test
```

Or trigger from the Actions tab with **Smoke test** checked.
This uses a synthetic fixture and confirms all metric extraction, report generation,
and file writing work correctly.

### Single-period quick run

```bash
# Both boost states for one period only (uses cache if present)
python scripts/run_cluster_validation.py --period covid_2020

# Force fresh API calls
python scripts/run_cluster_validation.py --period covid_2020 --force
```
